# DeivysCraft

DeivysCraft est un jeu de fusion inspiré d'Infinite Craft, centré sur la pop culture, les créateurs, le cinéma, les jeux vidéo, la musique et bien plus.

## Jouer

Le projet est un site statique autonome. Le fichier `index.html` contient l'interface, le moteur de jeu et la base de données publique.

### Modes
- Mode libre : découverte et collection persistante
- Contre la montre : trouver une cible le plus vite possible
- Speedrun : trouver une cible avant la fin du timer
- Objectifs filtrables par catégorie et difficulté
- Système d'indices progressifs
- Récapitulatif du chemin gagnant et records locaux

## Déploiement Vercel

Aucune commande de build n'est nécessaire.

- Framework Preset : Other
- Build Command : laisser vide
- Output Directory : laisser vide
- Root Directory : `./`

Vercel peut déployer directement la branche `main`.
